# PG素材管理系统

**PGB1** — 2D游戏特效师的文件整理工具

**当前版本**：V2.8.14  
**技术栈**：Tauri 2.x（Rust + Vue 3 + TypeScript）  
**目标平台**：Windows  
**开发者**：Fuchikami

---

## 产品简介

为2D游戏特效师设计的专业素材管理工具，解决日常工作中文件整理、格式转换、上传管理等繁琐流程。

### 核心功能

- **项目管理** — 项目卡片列表、截止日期、进度追踪
- **任务系统** — 树状任务结构、任务模板、子任务管理、自动进度判定
- **素材管理** — 双视图模式（树形分类 / 名称排序）、素材卡片、侧边栏详情预览
- **文件工作流** — 规范化 → 缩放 → 格式转换 → 完成 → 上传，全流程自动化
- **贴图板** — 独立窗口、多标签、画笔/箭头/矩形/椭圆/橡皮擦/文字工具
- **翻译** — 全局快捷键呼出置顶窗口，Gemini API 双语翻译
- **日报打卡** — WebView 自动化打卡、提醒弹窗、定时任务
- **笔记系统** — Markdown 编辑器，素材级/任务级笔记
- **快捷方式栏** — 左侧启动台，应用/文件夹/网页三种类型
- **国际化** — 中文/英文双语支持
- **自动更新** — 内置检测与一键更新

### 技术特性

- 毛玻璃（Glassmorphism）UI，明暗双主题
- 自定义字体（猫啃网糖圆体）
- 系统托盘常驻，关闭最小化到后台
- 序列帧 Canvas 实时预览
- PSD/PSB 缩略图生成与磁盘缓存
- PDF 翻译（Gemini API + CJK 字体嵌入）
- 新手引导系统

# Sharp Grid 全应用深色统一设计

## 目标

在不改变功能、路由、信息层级和页面布局的前提下，把主页已验收的 Sharp Grid「质感精装层」统一扩展到主应用、全部页面、公共组件、弹窗和独立窗口。

## 已裁决边界

- 本轮只升级深色主题；浅色主题保留现状。
- 全部窗口均在范围内，包括提醒、翻译、贴图板和所有弹窗。
- 移除主页临时“原版 / 精装”开关；深色主题直接启用 Sharp Grid。
- 不改业务逻辑、数据流、导航结构、控件位置和功能布局。
- 不新增第三方 UI 库，不新增运行时依赖。

## 视觉架构

以 `src/styles/design-system.css` 为唯一变量 SSOT：Sharp Grid 灰阶、状态强调色、表面高光、点阵、蚀刻线、字体、动效和层级全部进入 `:root[data-theme="dark"]`。`src/styles/sharp-grid.css` 只保留组件配方，不再定义第二套主题变量。

全局深色风格分为四层：

1. 工作区：纯深灰底、克制的 24px 工程网格，无蓝色大面积染底。
2. 表面：微渐变、1px 顶边高光、底边暗线和弱点阵，不使用毛玻璃与大模糊阴影。
3. 交互：按钮、输入、Tab、卡片、菜单统一锐角与短促 140–200ms 动效；焦点态清晰可见。
4. 状态：蓝/绿/橙/红只编码选择、进度、警告和危险操作；普通类型标签保持中性灰。

## 覆盖策略

- 共享外壳：MainLayout、TitleBar、StatusBar、Sidebar、WindowControls。
- 内容组件：四类卡片、预览、侧边详情、笔记、文件夹浏览器。
- 控件组件：按钮、输入、选择器、Tab、标签、进度条、下拉菜单。
- 弹窗体系：通用 Dialog、项目/快捷方式/子任务/引导/更新/上传等弹窗。
- 页面体系：主页、项目、任务、工作流、素材、时光机、设置及其子页。
- 独立窗口：ReminderPage、TranslatorPage、PinboardPage。

## 风险控制

- 保留所有模板结构和事件绑定，避免功能回归。
- 全局选择器限定在 `:root[data-theme="dark"]`，不污染浅色主题。
- 复用既有 CSS 变量检查和 Vue/TypeScript 构建；新增主题覆盖检查，防止试点开关或局部作用域残留。
- 尊重 `prefers-reduced-motion`，并保持键盘焦点可见。

## 1. 交互形态（已确认）

视频控制条下方多一行「对比工具栏」，同组 ≥ 2 个版本时才渲染。

| 控件组 | 内容 | 说明 |
|-------|------|------|
| 开关 | `打开对比` / `关闭对比` | 打开后 B 默认 = 上一版（A 已是最旧版时取下一版） |
| 版本菜单（对比打开后出现） | `[当前 B 标签] ▾` | 下拉列出组内其他版本，当前项打 ✓；需要时用户自己换 |
| 布局循环（对比打开后出现） | `并排` ⇄ `滑动` | 一个按钮显示当前布局名，点一下切到另一个。并排：左 A 右 B 各半，角标 `A · 版本 3` / `B · 版本 2`；滑动：两路叠同一画框，竖线可拖，线左 A 线右 B |
| 对齐（对比打开后出现） | `对齐` → 展开 `−1s` `−1帧` `+0.00s` `+1帧` `+1s` `归零` | 默认收起成一个按钮；收起且偏移非零时文案带偏移量（`对齐 +1.03s`）。**B 时间 = A 时间 + 偏移**；`Shift+←/→` 调 ±1 帧 |

> 2026-09-15 第二版：产品总监把第一版的「普通 / 上一版 / 所选」三段式改成开关 + 菜单，布局改循环按钮，偏移组折叠进「对齐」。

- 进度条 / 播放键 / 空格 / ←→ 只操作 A，B 被动跟随；B 永远静音
- 默认循环播放（2026-09-15 追加）：A 带 `loop`，循环回开头触发 `seeked` → B 硬对齐跟回；B 不带 loop
- B 选择器住在播放器内部（下拉），因为页内全屏会隐藏侧栏「版本历史」区块（`TaskPage.vue` 全局样式）
- 切到对比模式时自动进入页内全屏；退出对比不自动退全屏

## 3. 同步引擎（`useVideoCompare`）

A 是主时钟，B 只被动对齐：

```
targetB = A.currentTime + offsetSec

alignB(hard):
  B 未加载 metadata → 返回（loadedmetadata 时再来一次）
  targetB 越界（< 0 或 > B.duration）→ B.pause()，B 定格在最近的边界帧
  hard 或 |B.currentTime − targetB| > 漂移容差 → B.currentTime = targetB
  A 在播且 B 暂停 → B.play()

A 事件：
  play    → alignB(hard) + 启动巡检（setInterval 100ms，循环内 alignB(soft)，只在漂移超容差时纠偏，避免每帧 seek 卡顿）
  playing → alignB(hard)（A 真正出画时补一次：起播延迟会让先起跑的 B 领先一截）
  pause   → 停巡检 + B.pause() + alignB(hard)
  seeked  → alignB(hard)（拖进度条 / 逐帧 都走这里）
偏移变化 → alignB(hard)
B loadedmetadata → alignB(hard)（A 已在播则补开巡检）
```

为什么巡检用 setInterval 而不是 rAF：实测 WebView 不合成（窗口被遮 / 截图态）时 rAF 一次都不触发，同步会整个停摆。

`b.play()` 被拒（页面隐藏时 Chromium 主动暂停静音视频）后巡检停止重试，等下一次显式动作；否则 B 每 100ms seek+play 抽搐一次。

**滑动布局的裁剪方式**（2026-09-15 修）：第一版给 B `<video>` 直接上 `clip-path: inset()`，产品总监反馈滑动模式播不了（并排正常）。改为 `.video-b-slot` 槽位：并排时 `display: contents`，滑动时变成分割线右侧 `overflow: hidden` 的裁剪窗，B 在窗内 `width: calc(100% / (1 − r))` 撑回画框全宽右对齐。视频是独立合成层，clip-path 走遮罩路径，WebView2 两个视频层叠加 + 遮罩不可靠；overflow 是最朴素的 ClipNode。

实测（浏览器 harness，两段远程示例视频）：播放中漂移稳定在 ~0.07s（容差内，不触发纠偏），暂停后硬对齐到 0.0000。

## 4. 状态规则

| 事件 | 处理 |
|------|------|
| A 换版本（版本历史点选）| 对比保持打开，B 重新按「用户所选 ?? 上一版」解析；所选撞上新 A → 退回上一版 |
| 配对（A 或 B 路径）变化 | 偏移归零 |
| 关闭再打开 | 不清用户的版本选择 |
| 候选列表消失（侧栏换组 / 关闭）| 关闭对比 |
| B 加载失败 | `console.error` + 关闭对比（不静默） |

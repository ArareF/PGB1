精装版做了什么（全部不破「无玻璃 / 无大阴影 / 无大圆角」铁律）

  • 顶边高光 + 底边暗线：1px 实线（blur=0，非发光），模拟上方光源，治"平"
  • 表面微渐变 ~2%：金属漆面而非玻璃，给死色一点起伏
  • 磨砂噪点 3.5%：消除纯色"数字感"，复用 DesignSystem 既有噪点法
  • 蚀刻分隔线：暗线 + 下方一道微高光，呈"刻进去"的内凹感
  • 工业小料：右上编号角标 N° + 登记十字 + 四角铆钉点（落实文档 §10）
  • 排版重音：项目名 17px / 百分比 22px 成 hero，meta 压暗退后
  • 仪表读数块：meta 改"标签在上 / 等宽数值在下"，竖线分栏，对齐即秩序
  • 进度刻度仪：进度条加刻度短线 + 等宽读数，从墙纸变管线刻度
  • 选中书签角：左上蓝色切角三角，比纯边框更"被选中"
  • 停用斜纹：未开始卡叠 45° 斜纹"停用"纹理，不只是降透明

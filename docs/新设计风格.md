PG Asset Control / Sharp Grid System  
  
深色 2D 扁平化工业资产管理 UI。整体放弃玻璃、圆角和苹果式柔和质感，改用锐利矩形、直角面板、大块深蓝灰背景、清晰网格、细分割线和少量强调色。背景为深蓝黑 #0B0F14，主工作区为 #111820，面板为 #18212B，卡片为 #26323E。不用纯黑，不用半透明模糊。  
  
界面由左侧垂直导航、顶部系统状态栏、当前路径栏、主内容区和右侧 Inspector 组成。所有元素保持直角或极小 2px 圆角。层级通过大色块、明度、边框、分割线和间距表达。强调色只用于左侧选中条、顶部状态线、卡片边缘色带、书签角标、选中边框和少量按钮高亮。  
  
左侧导航为 72px 宽深色矩形栏，选中项使用 4px 蓝色竖线。顶部状态栏高度 52px，平直信息排布，不做胶囊。项目页使用 3 列矩形项目卡片，卡片顶部或左侧有状态色带，底部细进度条。任务页使用矩形任务卡片，按状态用蓝、绿、黄、红、灰色边条区分。素材页做成资产管理器风格，顶部有路径条和工具按钮，素材卡片缩略图和信息区分离，选中项用蓝色外框和小书签标记。右侧 Inspector 为直角深色详情面板，包含大预览、两列属性表格和底部固定操作栏。  
  
整体气质：冷静、硬朗、规整、工业秩序、深色生产工具、轻量数据面板。避免霓虹、避免大圆角、避免玻璃、避免厚阴影、避免可爱按钮。

## 12. Tech Lead 修订与补充（2026-06-10）

> 以下修订已全部落在可交互示意稿 `docs/新设计风格示意.html` 中，打开即可对照验收。
> 标 ⚠ 的条目涉及既有产品决策变更，需产品总监裁决。

### 12.1 修正草案内部矛盾：卡片底色统一

§2 色板定义卡片背景为 `#26323E`，§7 项目卡片却写 `#18212B`。统一为分层规则：

| 层级 | 颜色 | 用途 |
|------|------|------|
| body（绝对底，不可见） | `#000000` | 被工作区完全覆盖 |
| 主工作区 | `#0D0D0D` | 页面底（最深可见层，原 #0B0F14 的角色） |
| 左侧导航 | `#141414` | 导航面板 |
| 一级面板/卡片/路径条 | `#1A1A1A` | 落在工作区上的所有面板 |
| 二级面板/Inspector | `#222222` | 卡片 hover、Inspector |
| 三级浮层 | `#2B2B2B` | 下拉、弹窗、Inspector 内嵌块 |
| 选中底 | `#353535` | hover/selected 状态 |

口诀：**每抬一层，亮一档；同层永远同色；全程无蓝调，纯灰度变化。**

> **色调说明（2026-06-10 修订）**：原草案背景色带有明显蓝调（navy 系），现改为纯灰度系统。强调色（蓝/青/绿/黄/红）依然保留，但只出现在状态色带、选中边框、标签等语义性元素上，不渗入背景层。

### 12.2 字体系统（草案未定义）

猫啃网糖圆体与工业锐角风格完全冲突，本次必须随风格一起换：

- **标题/界面文字**：Chakra Petch（方正工程感，免费可商用），中文回退系统黑体（Microsoft YaHei UI / 思源黑体）
- **数据/路径/文件名/编号**：IBM Plex Mono 等宽字体 —— **所有数字一律等宽，对齐即秩序**，这是工业感成立的关键，比颜色更重要
- 全大写英文标注（DEADLINE / ASSETS / STAGE）配 0.1em 字距，作为装饰性信息层

### 12.3 ⚠ 导航适配实际产品结构

> **⛔ 已被推翻 → 见 §13.1**：本条曾把「时光机/贴图板/打卡/翻译」放进左侧导航，产品总监评审认定这些零碎功能不该占大板块；左栏改为快捷启动台。下文保留作决策轨迹。

草案 §5 的「项目/任务/素材/发布/团队」是平行频道结构，与 PGB1 实际的三级钻取（主页→项目→任务）不符，且「发布/团队」功能不存在。修正为：

- 左侧 72px 导航放**功能入口**：主页 / 时光机 / 贴图板 / 打卡 / 翻译 / 设置
- 项目→任务的**层级**交给路径条表达，导航不承担层级

### 12.4 ⚠ 路径条与「无面包屑」旧决策冲突

> **⛔ 已被推翻 → 见 §13.2**：产品总监裁决维持「不要面包屑」，改为返回按钮 + 当前页标题。下文保留作决策轨迹。

既有决策是「不要面包屑，用返回按钮逐级返回」。但 Sharp Grid 的路径条（§4/§9）本质就是面包屑。建议：**返回按钮 + 可点击路径段并存** —— 返回键保留逐级返回肌肉记忆，路径段提供跳级能力。示意稿按此实现，请体验后裁决。

### 12.5 分段式进度条（替代普通细进度条）

> **🔄 已修订 → 见 §13.6**：段数从"固定 18 段/百分比"改为"一格 = 一个真实子单位"，并斜切为平行四边形（首尾竖直）。

进度条改为 2px 间隔的分段块（默认 18 段），更贴合"管线刻度"气质，且一眼可读档位。普通平滑进度条在该风格里显得软。

### 12.6 切角签名细节（Corner Notch）

整套 UI 唯一允许的非直角元素：右下 8px 斜切角，**只用于统计块和主操作按钮**两处，作为视觉签名。其余一切元素保持纯直角。滥用即廉价。

> 注：统计块已取消（§13.4），切角现**仅剩主操作按钮一处**。进度条的平行四边形斜切是另一套形状语言（§13.6），不属于此切角签名。

### 12.7 蓝图网格底纹 + 角落基准标记

主工作区底层加 24px 网格线（~4% 透明度）+ 角落十字基准标记「+」，强化工业图纸氛围。纯 CSS 渐变实现，零性能成本。

### 12.8 选中态语法表（收口为 SSOT）

> **🔄 卡片/素材两行已修订 → 见 §14.3**：卡片选中色由"固定蓝"改为"跟随状态色 `--sel`"（框/顶线/书签角统一）；书签角尺寸 17→27px。下表保留作轨迹，冲突以 §14.3 为准。

| 元素 | 选中表达 | 规格 |
|------|---------|------|
| 导航项 | 左侧竖条 + 底色提亮 | 4px |
| 卡片 | 蓝边框 + 顶部色线 | 1px + 3px |
| 筛选项 | 底部色线 | 3px |
| 素材 | 蓝外框 + 左上书签角 | 2px + 17px 三角 |

规则：一个元素只用一种选中表达；全局禁止发光（box-shadow blur 恒为 0）。
固定值：色带 4px / 选中线 3px / 标签边框 1px / 标签高 20px。

### 12.9 类型标签去色

「序列帧/静帧/视频/源文件」等类型标签一律中性灰（1px `#344250` 边框），**颜色只留给状态**（进行中/待确认/完成/返修）。否则满屏彩色标签会摧毁"少量高亮"原则。

### 12.10 PGB1 专属组件映射

> 注：下表首行「顶部状态栏 WORKING 计时」随顶栏改版作废（§13.3），打卡状态改在主页快捷功能区表达。其余映射仍有效。

| 草案概念 | 落到 PGB1 实际功能 |
|---------|-------------------|
| 顶部状态栏 WORKING 计时 | 日报打卡的出勤/加班状态 |
| Inspector 属性表 | 现有素材详情侧边栏（360px 直角化） |
| Inspector 增加「进度链条」组件 | 00_original→01_scale→02_done→03_preview 四节点，过站绿/当前蓝/未到灰 |
| 素材工具栏 | 刷新/多选/规范化(主操作蓝边框)/缩放/转换 |
| 已上传标记 | 6px 绿色小方点（草案允许的"极小辅助状态点"） |

### 12.11 ⚠ 范围裁决项

1. **明亮主题**：建议本次砍掉，暗色即本体（工业控制台没有白天模式）。保留双主题会让全部 token 翻倍。
2. **未开始项**：整卡透明度降至 62% + 灰色带，不再单独设计空态样式。

### 12.12 工程红利（确认项，非决策项）

新风格天然移除全部 `backdrop-filter` 与大阴影，与现有性能铁律（卡片禁 backdrop-filter、同层兄弟模糊冲突）完全兼容 —— 这次改版滚动性能只升不降。迁移时优先替换 DesignSystem 变量层，组件结构基本不动。

## 14. 质感精装层（2026-06-18 定稿）

> 解决问题：Sharp Grid 骨架对，但落地一版"太 AI / 太平 / 缺细节"。本节是在 §1–13 骨架之上叠加的**质感层**，全部不破三条铁律——**无玻璃、无大阴影模糊、无大圆角**。
> **canonical 参考**：`docs/新设计风格-精装样板.html`（主页项目卡 + 组件样板，含 `原版 ⇄ 精装` 对比开关与点阵控制台）。
> 凡与 §12.8「选中=蓝」冲突处，**以本节 §14.3 为准**。

### 14.1 核心诊断（为什么旧版"平 / AI 味"）

| 病 | 根因 | 解法（本节对应） |
|----|------|-----------------|
| 太平 | 为反玻璃把"光"也戒了——每个面都是死色填充，无顶边高光/无表面起伏 | §14.2 顶边高光 + 微渐变 + 点阵光照 |
| 缺细节 | 文档 §10 列的工业小料（角标/铆钉/刻度）基本没实现 | §14.4 工业小料 |
| AI 味 | 节奏处处均匀、无视觉主角；强调色平涂成墙纸 | §14.5 排版重音 + §14.3 选中收口 |

### 14.2 质感原料 Token（SSOT，迁移 DesignSystem 时整组带走）

```css
/* 顶边高光 + 底边暗线：1px 实线（blur=0，是"光"不是"发光"，不违反禁令） */
--edge-hi: inset 0 1px 0 0 rgba(255,255,255,.045);
--edge-lo: inset 0 -1px 0 0 rgba(0,0,0,.45);

/* 磨砂噪点：SVG feTurbulence，叠 3.5% / mix-blend overlay，消除纯色"数字感"
   （沿用 DesignSystem 既有噪点法，baseFrequency 0.9） */
--noise: url("data:image/svg+xml,...feTurbulence...");

/* 点阵光照·定稿值（"斜上方光照"图形化：左上密如实心 → 右下渐疏成点 → 隐去） */
--dot-gap:   8.5px;   /* 点间距 */
--dot-r:     .8px;    /* 点半径 */
--dot-fade:  45%;     /* 对角 mask 透明位（光铺多远） */
--dot-alpha: .18;     /* 点亮度 */
```

**面板/卡片表面三件套**（叠加顺序）：
1. **表面微渐变**：`linear-gradient(180deg,#1e1e1e,#181818)`——上浅下深 ~2%，金属漆面而非玻璃。
2. **顶边高光线**（`--edge-hi`）= "实心光源"，落在最顶 1px。
3. **点阵光照**：顶边线之下接一层网点，从左上沿 135° 对角渐隐——"从实心到点阵"。
   ```css
   .surface::after{                 /* 落在文字之下、底色之上（z-index:-1，不糊字） */
     background-image:radial-gradient(circle,
       rgba(255,255,255,var(--dot-alpha)) var(--dot-r),
       transparent calc(var(--dot-r) + .2px));
     background-size:var(--dot-gap) var(--dot-gap);
     mask-image:linear-gradient(135deg,#000 0%,rgba(0,0,0,.55) 16%,transparent var(--dot-fade));
   }
   ```
4. **蚀刻分隔线**：区块分隔改双线——暗线 + 下方一道 `0 1px 0 rgba(255,255,255,.03)` 微高光，呈内凹刻痕。

### 14.3 选中态语法收口：选中 = 状态色（修订 §12.8）

> **推翻 §12.8 的「卡片 = 蓝边框」**。验收结论：选中框/顶线/书签角**统一跟随卡片状态色**，让选中卡在自己的色系里整体亮起，信息量高于固定蓝。

实现：每张卡按状态定义一个 `--sel` 变量，三处选中表达统一引用（SSOT 一处定义）：

```css
.card.st-progress{--sel:var(--acc-blue)}   /* 进行中 */
.card.st-review  {--sel:var(--acc-amber)}  /* 待确认 */
.card.st-done    {--sel:var(--acc-green)}  /* 已完成 */
.card.st-revision{--sel:var(--acc-red)}    /* 返修 */
.card.st-idle    {--sel:var(--tx-dis)}     /* 未开始 */

.card.sel{ border-color:var(--sel);
           box-shadow:var(--edge-hi),var(--edge-lo),
                      inset 0 3px 0 var(--sel),     /* 顶线 */
                      inset 0 0 0 1px var(--sel); } /* 内框 */
.bookmark{ background:var(--sel); }                 /* 左上书签角 */
```

| 元素 | 选中表达 | 颜色 | 规格 |
|------|---------|------|------|
| 卡片 | 内框 + 顶线 + 左上书签角 | **状态色 `--sel`** | 1px + 3px + 27px 三角 |
| 导航项 | 左侧竖条 + 底色提亮 | 蓝 | 4px |
| 筛选 chip | 底部色线（从左 scaleX 生长） | 状态色 | 3px |
| 素材 | 2px 外框 + 左上书签角 | 蓝（选中语义） | 2px + 书签 |

**书签角细则**：仅选中时出现（非选中无角，杜绝灰色半吊子态）；尺寸 27px；缩放弹入动画见 §14.6。
（书签角元素**不要**挂全局 `craft-only` 类——会被统一显示规则覆盖而常驻，须只受 `.sel` 控制。此为踩过的坑。）

### 14.4 工业小料（落实 §10，治"缺细节"）

- **编号角标**：卡片右上 `N°226` 等宽 + 登记十字 `+`。
- **铆钉点**：四角 2px 暗点 + 1px 微高光，金属面板螺丝感。
- **停用斜纹**：未开始卡叠 45° 斜纹——**必须用微亮线** `rgba(255,255,255,.055)`，黑线叠黑底等于隐形（踩过的坑）。
- **切角签名**：右下 8px 斜切，全局**仅主操作按钮**一处（统计块已取消，§13.4）。

### 14.5 排版重音（治"AI 味"）

- 项目名 17px / 百分比 22px 成 **hero**，meta 压暗退后，打破"处处均匀"。
- meta 改「标签在上 / 等宽数值在下」的仪表读数块，竖线分栏——对齐即秩序。
- 进度条加刻度短线 + 等宽读数，从墙纸进度条变"管线刻度仪"。

### 14.6 动效（克制、利落，140–200ms ease-out，不弹跳）

| 时机 | 效果 | 规格 |
|------|------|------|
| 选中 | 书签角从左上缩放弹入（轻微过冲锁定感） | `transform:scale(0→1)` `cubic-bezier(.34,1.45,.5,1)` .2s |
| 选中 | 蓝/状态色框 + 顶线淡入生长（非硬切） | box-shadow 补"透明占位层"使层数一致才能过渡，.2s |
| hover | 整卡轻浮 `-2px`（不放大不投影，沿用 `--card-hover-lift`） | transform .16s |
| hover | 左侧状态色带"通电点亮" | `filter:brightness(1.4)` .16s |

> 关键：hover 走 `transform`/`filter`，**不碰 box-shadow**——否则与选中态蓝框抢同优先级，hover 选中卡会丢顶线。

### 14.7 组件质感基线（精装样板已实现）

- **按钮**：描边 + 微渐变 + 顶边高光，hover 抬起 -1px；无实心大色块（守"少量高亮"）。主操作 = 蓝边 + 切角；accent 蓝 / ghost 幽灵 / danger 红。
- **侧边栏图标块**：金属化（渐变 + 高光 + 噪点），hover 抬起 -2px；三类快捷方式色分（应用蓝/文件夹黄/网页青）。
- **筛选 chip**：下划线从左 `scaleX` 生长。
- **标签**：彩色只给状态，类型标签（序列帧/静帧）一律中性灰（守 §12.9）。
- **输入框**：内凹井 `inset 0 1px 2px rgba(0,0,0,.5)`，像嵌进面板的凹槽。

### 14.8 实装迁移备注

- 本节 Token 迁入真实代码时，整组进 `DesignSystem`（新风格分支）变量层，组件只引用、不硬编码。
- 点阵光照的四个旋钮（`--dot-*`）建议保留为可调变量，便于后续整体加减质感。
- 迁移优先级：**先替换变量层 → 组件结构基本不动**（§12.12 工程红利仍成立：新风格无 backdrop-filter / 无大阴影，性能只升不降）。

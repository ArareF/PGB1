选中态语法 / SELECTION GRAMMAR

导航项  左侧 4px 竖条 + 底色提亮band-4

素材  2px 蓝外框 + 左上书签角（选中恒蓝）border-2+bookmark
规则：一个元素只用一种选中表达，严禁发光（box-shadow blur = 0）。
选中 = 状态色（--sel，§14.3）：项目/任务卡随状态变色，书签角与素材选中恒蓝（蓝 = 选中语义）。
